# 常见问题

## 游戏中看不到辅助线或提醒

1. 先在“画面实验室”打开一种图案，用窗口内预览确认它可见。四个方向可能被关闭；配色和透明度也会影响可见度。
2. 将游戏切到无边框全屏，在概览选中真正的游戏窗口并点击“开始辅助”。前台切到其他程序时，正常游戏覆盖层会隐藏。
3. 看看页首是否显示“已暂时隐藏”，必要时恢复辅助。如果游戏重建窗口，结束本次体验，再刷新和重新绑定。
4. 独占全屏或 HDR 下有问题时，可先用 SDR 无边框全屏做对照。受保护画面可能限制覆盖层。

## 手柄能用吗？

固定参考图案和计时不依赖手柄类型。只有高级遮罩的右摇杆动态增强使用 XInput；系统未识别为 XInput 时，该增强可能不生效。软件不会修改摇杆灵敏度或拦截输入。

## 快捷键没反应，或关闭窗口后程序仍在运行

在“使用与快捷键”检查实际组合。默认组合被占用时，程序会尝试加 Shift 的备用组。关闭主窗口会收起到系统托盘；右键托盘图标可退出程序。升级前也请先从托盘退出旧版。

## 怎么检查下载是否完整？

在 PowerShell 中切换到下载目录，运行：

```powershell
Get-FileHash -LiteralPath .\StillFrame-2.2.0-win-x64.zip -Algorithm SHA256
```

将结果与同一发布页 `SHA256SUMS.txt` 中便携包对应的值比较。解压整个 ZIP，保留 EXE 同目录的运行库。发布版没有商业代码签名，请从项目 Releases 下载。

## 如何反馈问题？

到 [GitHub Issues](https://github.com/dindding17/StillFrame/issues) 描述软件版本、Windows 版本、游戏窗口模式、显示缩放、HDR 状态和复现步骤。涉及手柄时可补充型号与连接方式。日志位于 `%LOCALAPPDATA%\StillFrame`，仅在发生异常时生成；分享前请检查并去掉私人内容，无需发送体验历史或私人笔记。
