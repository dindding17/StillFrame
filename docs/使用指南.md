# 静界 StillFrame 2.2

Windows 11 x64 游戏舒适辅助工具。中文、离线运行，无需账户。

**默认关闭所有辅助画面，保留游戏原亮度与视野，只提供前台计时和休息提醒。** 在“画面实验室”看过预览后，再按需选择视觉参考。

## 安装与开始

1. 完整解压 `StillFrame-2.2.0-win-x64.zip`，运行目录中的 `StillFrame.exe`。包含所需 .NET 运行库，无需另行安装。
2. 如旧版仍在运行，先通过旧版托盘菜单退出。关闭主窗口只是收起到托盘。
3. 启动游戏，改为**无边框全屏**。在概览中刷新并选择真正显示游戏画面的窗口。
4. 直接点击“开始辅助”即可使用计时和提醒，默认不会添加参考点、辅助线、细框或变暗。
5. 想试视觉辅助时，进入“画面实验室”。左侧实时预览，右侧调整；先一次开启一种元素。
6. 切回游戏，只在游戏处于前台时累计时间；默认 10 分钟首次提醒、15 分钟再次提醒。提醒不暂停游戏。
7. 有不适就结束，不用等到提醒。回到静界点击“结束并记录”，可自愿记录不适程度，或以后补填。

本版本未提供商业代码签名。首次运行如出现来源提示，请核对文件来源。

## 画面实验室

界面采用雾白、浅蓝灰和低饱和青蓝。导航图标与文字使用固定网格居中对齐，概览以两列等高面板分区；画面实验室提供图案、颜色和参数三个页签。程序、窗口和托盘使用统一的取景框图标；ICO 包含 16～256 像素的九档尺寸。

窗口内使用静态示意场景，不截取或上传游戏画面。预览和覆盖层共用绘制代码；示意场景不代表实际游戏性能，具体尺寸与对比效果仍以目标屏幕为准。

| 元素 | 作用与显示方式 |
| --- | --- |
| 四向短线 | 上下左右四段向内短线，四方向可独立关闭 |
| 四向三角 | 四个朝向中心的三角标，可空心 / 实心 |
| 方向折线 | 四方向的开放折线标记 |
| 菱形锚点 | 四方向菱形标记，可空心 / 实心 |
| 边缘角标 | 四角的短 L 形线，中央不添加线条 |
| 侧边短线 | 左右两侧的短水平线，不横贯屏幕 |
| 三分刻度 | 在四边三分位置放置短刻度，中央保持空白 |
| 边缘标尺 | 四周疏落刻度，不在中央铺网格 |
| 留空水平线 | 左右两段水平参考线，中央 40% 留空 |
| 中空十字 | 中心留小间隙的四段短线 |
| 中心空心环 | 中心圆环，半径可调 |
| 中心参考点 | 固定在屏幕中心的小点，可调直径 |
| 细参考框 | 固定细框，提供屏幕参照 |
| 边缘变暗 | 收纳在高级选项中，默认关闭；可能影响 HUD 和体验 |

线宽、距边缘距离、颜色、不透明度可调，线型可选实线 / 虚线 / 点线；空心环半径独立可调。图库包含“仅计时”及十二种视觉参考起点，每项都有示意缩略图。选择起点会清除上一项的图形，并关闭变暗与动态增强；如需组合，可在右侧分别勾选。

“按住看原图”支持鼠标按住，或键盘聚焦后按住空格 / Enter，仅临时隐藏窗口内的预览元素，不修改设置。松开或失去焦点恢复。“全屏预览 15 秒”在当前显示器上临时显示覆盖层，不累计游玩时间，可立即隐藏。

可选的 XInput 右摇杆增强仅作用于变暗遮罩：约 0.22 秒渐强、0.45 秒渐弱；不拦截游戏输入。读取最多四个 XInput 槽位并取最大右摇杆幅度，请避免其他手柄被误触。未识别手柄时，固定参考元素仍可使用。

辅助线固定在屏幕上，不代表游戏内真实地平线，也不会跟踪游戏镜头。其效果因人而异，若分散注意力、妨碍操作或更不舒服，就关闭。


### 四方向与自由改色

“方向与颜色”页签可分别启用上、下、左、右。四向短线、三角、折线和菱形按对应方向显示；已有周边线段按距离最近的边归属方向，中央点、环和十字不受四周开关影响。

每个方向可输入 `#RRGGBB` 或打开 Windows 颜色选择器。留空跟随全局色；全局留空使用下方颜色预设。四个方向可以各用一种颜色，右侧色块显示解析后的实际颜色。无效 HEX 不应用，界面提示修正。方向标记大小、图案空心 / 实心及透明度可调。

关闭全部方向后，周边图案将隐藏，但启用的中央图案仍会显示。选择新预设保留方向与颜色偏好；如果预设没有显示，检查方向开关。

## 快捷键与计时

| 默认快捷键 | 功能 |
| --- | --- |
| Ctrl + Alt + F8 | 尚未开始体验时，绑定当前前台窗口 |
| Ctrl + Alt + F9 | 隐藏 / 恢复所有辅助画面和提醒；计时继续 |
| Ctrl + Alt + F10 | 暂停 / 继续计时，不暂停游戏 |
| Ctrl + Alt + F11 | 立即隐藏覆盖层并取消预览，不改变计时状态 |

默认组合有任意一个被占用时，整组尝试 `Ctrl + Alt + Shift + F8～F11`。绑定提示、全屏预览提示和“使用与快捷键”页面显示实际组合；备用组合仍冲突时会列出失败项目，可使用窗口或托盘操作。

只累计所选窗口在前台的时间。系统睡眠或阻塞超过 2 秒的间隔不计入。两次提醒每场各触发一次，不持续催促。默认无辅助时，只有提醒会短暂显示；手动隐藏总开关会连同提醒一起隐藏。

正常退出会保存未结束的体验为未评分记录；强制结束进程或断电无法保证保存当前体验。

## 游戏设置与效果记录

为《影之刃零》提供个人清单：动态模糊、镜头晃动、镜头灵敏度与加速、视野或镜头距离、帧率与显示设置。以游戏实际选项为准，由用户手动调整，不修改游戏文件。

当前使用环境记录为创维 27X4Q、75 Hz、约 50～60 FPS、约 60 cm。先比较稳定帧率与帧时间波动，再核对垂直同步和可变刷新率；不要仅因屏幕为 75 Hz 就盲目将游戏锁到 75 FPS。

每次结束记录前台时长、末次完整配置、可留空的 0～10 不适程度和笔记，支持 CSV 导出。配置只代表结束时状态；中途修改过设置，请在笔记说明。

在充分恢复后的不同场次，以相近场景和相近短时长比较。先无辅助，再单独尝试角标、侧边短线或参考点。无需忍受恶心来完成比较。个人记录不能证明临床效果。

## 机制与边界

视觉运动与身体 / 前庭感受不一致，是视觉诱发晕动的一种主要解释。镜头晃动与帧时间不稳定可能增加负担。固定参考元素旨在提供视觉参照；遮罩尝试减弱周边运动刺激；提前提醒帮助控制连续暴露时间。

这些方法不能保证缓解，更不能保证消除眩晕。症状持续、明显加重或日常也出现时，应停止体验并考虑咨询医生。

- 目标 Windows 11 x64，优先 SDR 无边框全屏。独占全屏、HDR 或受保护画面可能限制覆盖层。
- 不注入游戏、不读写游戏进程、不修改游戏文件、不拦截输入、不采集游戏图像、不发网络请求。
- 游戏重启或重建窗口后，请结束当前体验再重新绑定；选择启动器不能跟随后续游戏进程。
- 原生 DualSense / DirectInput 不保证支持动态增强；不影响固定线条、参考点和提醒。
- 真实游戏兼容、XInput 实物手柄、不同 DPI 多屏和性能影响需要在家中电脑验证。

## 升级与本机数据

从 1.0 升级到 2.x 时，首次载入会关闭原来开启的视觉干预，符合“默认无辅助”的选择；保留游戏笔记、提醒时间与已有体验记录。在 2.x 中手动选过的配置之后会保留，不会每次启动都清空。从 2.x 升级保留已有选择、方向、颜色和笔记。

默认目录：`%LOCALAPPDATA%\StillFrame`。

- `settings.json`：个人设置与游戏笔记。
- `sessions.json`：体验记录。
- `.bak`：上次保存副本；损坏原文件不会被自动删除。
- `error.log`：仅发生异常时生成的本机诊断信息。

没有数据上传、账户或遥测。`STILLFRAME_DATA_DIR` 环境变量可指定替代目录，主要供测试。退出后删除程序目录即可卸载；清除个人数据需自行删除上述数据目录。

## 从源码构建

需要 Windows 和 .NET 10 SDK；无需第三方 NuGet 应用库。首次自包含发布可能需下载微软运行时包。

```powershell
.\build.ps1
```

图标源 SVG、ICO 和 PNG 位于 src/StillFrame/Assets。tools/New-BrandAssets.ps1 可在 Windows 上重新生成，无需外部绘图库。

脚本优先使用 `.tools/dotnet` 中的 SDK，否则使用 PATH 中的 SDK。运行核心检查、自包含发布并生成便携包、源码包与 SHA256 校验文件，输出到 `artifacts`。缓存不属于用户运行依赖。

验证范围与实测结果见随包《验证报告.md》；首次使用可参照《家中电脑验证清单.md》。
