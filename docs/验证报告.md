# 静界 2.2 验证报告

日期：2026-11-10。目标 Windows 11 x64；开发电脑不是实际游戏电脑。

## 本版改变

- 界面采用雾白、浅蓝灰与低饱和青蓝。固定图标槽位、统一控件居中、卡片间距与标题层级；概览使用两列等高面板，实验室采用预览 / 图库和三个设置页签。
- 参考 Microsoft Fluent 2 的网格、四像素间距及图文对齐原则，以及 Vercel Geist 的组件层级与选中状态。公开来源链接见使用说明，未复制品牌素材。
- 图库共十三项：全部关闭，以及十二种视觉参考起点。新增四向短线、四向三角、方向折线、菱形锚点，可与已有图案组合。
- 上下左右独立开关、独立 HEX 配色与颜色选择按钮；支持全局颜色和预设回退。方向标记尺寸、实心 / 空心、线型、线宽及不透明度可调。无效 HEX 不应用。
- 专属取景框图标用于 exe、窗口、界面和托盘；ICO 包含 16～256 像素九档尺寸，源码包含 PNG、SVG 及生成脚本。
- 新安装默认关闭全部视觉干预；保留 2.x 用户主动设置、笔记与记录。

## 验证

- 70 项核心检查通过，覆盖计时提醒、数据保存恢复、迁移、配置快照、图案几何边界、默认关闭、四方向筛选、颜色校验及回退、尺寸限制与完整配置序列化。颜色检查也拒绝内部空格和重复井号。
- 使用实际 WPF 控件离屏渲染 21 张图片，覆盖所有页面、新增样式及紧凑尺寸；预览和覆盖层共用绘制逻辑。
- 1360×840 与 1120×720 布局检查：四方向行的开关、HEX 输入框与颜色按钮中心偏差均为 0 DIP，输入框宽度均大于 100 DIP。检查结果写入开发输出目录 layout-audit.txt。
- 检查预览截图中的文本裁切、控件对齐、卡片宽度和页签内容拉伸。图库与长参数面板支持独立滚动，小窗口下仍可访问全部设置。
- 自包含 x64 发布包含所需 .NET 运行库、说明与许可证；校验发布包、源码包的 ZIP 内容、CRC 和 SHA256。

构建成功，但 NuGet 漏洞元数据服务不可达，产生 NU1900 警告；本次未完成在线漏洞元数据检查。应用代码不依赖第三方 NuGet 应用库。

离屏模式不显示主窗口、不注册全局快捷键、不操作桌面，数据隔离在输出目录。示例配色和图案不写入个人设置。离屏检查无法替代真实桌面交互和实际游戏验证。

## 尚未实测

本轮未使用桌面自动化，未实时点击系统颜色选择器、托盘或触发全局快捷键。颜色选择器使用系统对话框并指定主窗口归属；取消保留原值。图标已嵌入且离屏启动正常，目标电脑托盘实际显示仍需确认；请先从托盘退出旧版，再启动新版。

家中《影之刃零》的覆盖层、点击穿透、XInput 实物手柄、HDR、多 DPI 屏幕、FPS / 帧时间和个人舒适度仍需按随包清单短时验证。辅助图案不代表游戏内真实地平线，功能数量不等于缓解效果。

## 重现

在 Windows、.NET 10 SDK 环境运行 .\build.ps1；核心检查位于 tests/StillFrame.Checks。图标由 tools/New-BrandAssets.ps1 生成。

开发用离屏命令：StillFrame.exe --render-ui 输出目录。图片和 layout-audit.txt 保存在该目录，不修改用户设置。
