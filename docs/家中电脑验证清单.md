# 家中电脑首次验证 / 静界 2.2

先选熟悉的短场景，无需为验证达到 20 分钟。出现不适立即结束。

## 默认无辅助

- [ ] 从旧版托盘菜单退出后，再启动新版；关闭主窗口仅会收起到托盘。
- [ ] 首次启动显示“仅计时”和“视觉辅助 · 全部关闭”。从 1.0 升级也应如此，原笔记与历史保留。
- [ ] 游戏使用无边框全屏，在概览选择真正的游戏窗口并开始。
- [ ] 默认游戏不变暗、不出现参考点或线条；只有到时提醒会短暂显示。
- [ ] 切到其他应用停止计时，切回所选游戏继续。

## 画面实验室

- [ ] 窗口内预览初始没有覆盖元素；选择一个起点后，预览和勾选项同步。
- [ ] 图库十三个起点都有缩略图，选中项边框明确。
- [ ] 分别比较角标、侧边短线、三分刻度、边缘标尺、留空水平线、中空十字、空心环、点与细框。一次只试一种。
- [ ] 比较实线 / 虚线 / 点线，空心环半径可调；关闭后没有残留。
- [ ] 按住“按住看原图”显示原示意场景，松开恢复，不改配置。
- [ ] 线宽、距边缘、不透明度与颜色变化能实时预览。
- [ ] 需要时全屏预览 15 秒，隐藏快捷键有效；计时不增加。
- [ ] 切回游戏后，所选参考元素位置正确、操作与菜单不受影响。
- [ ] “仅计时 / 全部关闭”能关掉所有参考元素、变暗与动态增强。
- [ ] 重启 2.x 后保留自己主动选择的配置。

## 方向与颜色

- [ ] 分别关闭上 / 下 / 左 / 右，四向短线、三角、折线和菱形只保留启用方向。
- [ ] 中央点、环和十字不受周边方向开关影响。
- [ ] 四方向 HEX 可以独立填写，留空跟随全局；颜色按钮显示实际色块。
- [ ] 打开颜色选择器后取消不改变配置，选择后预览同步。
- [ ] 无效 HEX 会提示；修改为有效六位 HEX 后可恢复。
- [ ] 退出再启动后，方向、颜色、空心 / 实心和标记大小保留。
- [ ] 在当前屏幕缩放下，导航、方向标签、输入框与色块垂直对齐。

## 提醒与记录

- [ ] “预览提醒”能显示文字，不改变当前游戏计时。
- [ ] 如需验证真实提醒，可临时改为 1 / 2 分钟，验证后恢复 10 / 15。
- [ ] F10 仅暂停计时，暂停游戏需要自行操作。
- [ ] 结束后生成未评分记录，显示角标 / 短线等末次配置；能补填评分并重启保留。
- [ ] CSV 中文、设置、评分和笔记正确。

## 程序图标

- [ ] exe、窗口标题栏 / 任务切换和托盘显示同一枚青绿色取景框图标。
- [ ] 退出旧版后启动新版，托盘不再显示通用应用图标。Windows 可能保留旧图标缓存，不建议同时运行多个版本。
- [ ] 在常用显示缩放下，托盘小图标可辨识；右键与双击功能正常。

## 快捷键与显示模式

- [ ] 在“使用与快捷键”确认实际组合，默认带 Ctrl + Alt；遇冲突会尝试再加 Shift。
- [ ] F9 能隐藏 / 恢复，F11 能立即隐藏；隐藏总开关也会隐藏提醒。
- [ ] 分辨率或缩放改变后仍对齐；若游戏重建窗口，则结束体验再绑定。
- [ ] 若使用 HDR 或独占全屏遇到异常，先比较 SDR 无边框全屏。

## 高级遮罩 / 手柄（可完全跳过）

- [ ] 遮罩默认关闭，打开高级选项也不会自动启用。
- [ ] 只有启用遮罩后才能开启动态增强。
- [ ] 有 XInput 手柄时转镜头平滑加深；无手柄或拔出后固定参考元素正常。
- [ ] 若变暗、动态变化影响体验，关闭并保持“仅计时”或固定参考元素即可。

## 性能与实际感受

- [ ] 相同场景与设置，比较程序退出、默认仅计时、开启一项参考元素时的 FPS 与帧时间。
- [ ] 若明显掉帧、帧时间恶化或更不舒服，关闭相应元素；仍有问题则退出并反馈。
- [ ] 记录显卡、分辨率、显示缩放、HDR、手柄型号与连接方式，便于排查。
- [ ] 充分恢复后再进行不同场次的短时比较，不强行延长游玩。

反馈可描述“期待什么 / 实际发生什么”，不需要发送私人笔记或全部历史数据。
